# Размещение кода

Созданы Python-пакет и точка запуска `python -m claims_assistant`. Реализованы `presentation/telegram` и `runtime`; остальные каталоги зарезервированы для следующих этапов.

- `presentation/telegram/`: обработчики команд, проверка доступа, сообщения и кнопки. Загрузка пакета пока не реализована.
- `application/`: сценарии импорта, запуска анализа и получения отчёта; интерфейсы внешних зависимостей.
- `domain/`: сущности, показатели, правила приоритета и основания. Без сети и БД.
- `infrastructure/checko/`: запросы, схемы внешних ответов, преобразование в доменные факты.
- `infrastructure/llm/`: клиент модели, сборка контекста, проверка ответа.
- `infrastructure/excel/`: чтение согласованных шаблонов и запись итогового отчёта.
- `infrastructure/persistence/`: модели хранения, репозитории и файлы.
- `runtime/`: настройки, сборка зависимостей, запуск и остановка бота. Фоновые задания пока не реализованы.

Новые подпапки создаются при появлении соответствующего кода. Не выделять сервисы и универсальные абстракции заранее. Подробности — в [архитектуре](../../docs/architecture.md).

## Текст запроса для заказчика

Для первой версии «Помощника претензионщика» нужны:

1. Дата защиты и дата, к которой нужен готовый демонстрационный сценарий.
2. Обезличенный пример выгрузки контрагентов из 1С: сохранить названия листов, колонок, типы ячеек и характерные пустые значения. Достаточно небольшого примера с обычными и проблемными строками. Указать дату, на которую сформирован долг, валюту и смысл суммы долга/дней просрочки.
3. Примеры платежей и истории долга, если они доступны: даты, суммы, идентификаторы операций, период полноты платежей и сопоставимые срезы долга. По одному последнему платежу рост долга не вычисляется.
4. Пример журнала взаимодействий: связь с контрагентом, дата, ID записи, комментарий. Удалить персональные и конфиденциальные сведения, сохранив структуру.
5. Доступ Checko: кто предоставляет ключ, какие разделы доступны, тариф, квоты и допустимые расходы на тестирование. Нужны организация, финансовая отчётность и ЕФРСБ. Секрет передавать отдельно от файлов и документов, не в GitHub или карточке задачи.
6. Кто со стороны заказчика проверит итоговый отчёт и трактовку тревожных событий. Нужны несколько контрольных примеров с ожидаемым результатом и основаниями.

Если чего-то пока нет, указать ответственного и этап, к которому это будет предоставлено. Шаблоны проекта — предложение для согласования, а не требование перестроить 1С до просмотра реальных файлов.

## Предлагаемые контрольные сценарии

Это проект набора для согласования, не подтверждённые заказчиком случаи и не готовые правила юридической оценки.

| Сценарий | Что нужно проверить |
| --- | --- |
| Полные данные, подтверждённых внешних сигналов нет | Показываются факты, источники и период; отсутствие сигнала не выдаётся за гарантию оплаты |
| В источнике есть сообщение о банкротстве | Видны тип, дата, роль организации и основание; интерпретацию подтверждает специалист |
| Организация в ликвидации | Статус корректно сопоставлен, показаны источник и дата |
| История долга показывает рост | Сравниваются сопоставимые срезы; при отсутствии базы показатель неизвестен |
| Платежей нет в переданном фрагменте | Неполная история не трактуется как доказанное прекращение оплаты |
| Финансовая выручка снизилась | Сопоставлены годы и единицы; отсутствующий год не заменён нулём |
| Checko недоступен или квота исчерпана | Показана неполнота, отсутствие ответа не означает низкий риск |
| Повторный ИНН, ошибочная дата, конфликт сумм | Ошибки привязаны к строкам; нет незаметного объединения противоречивых сведений |
| Есть обещание оплаты в комментарии | Текст связан с записью; обещание не считается исполненным или нарушенным без достаточных данных |

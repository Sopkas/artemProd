# Контрольный пакет — 50 контрагентов (S2-06)

Синтетический пакet «Контрагенты» для сквозной проверки пути «файл → результат» на
демоданных. Генерируется детерминированно: `infrastructure/excel/control_package.py`,
`build_control_package()`. Дата анализа пакета — **01.09.2026** (`ANALYSIS_DATE`).

Источник истины — сам модуль: ожидаемые ошибки объявлены рядом со строками, которые их
порождают, а константы `EXPECTED_USABLE`, `EXPECTED_ISSUES`, `DEMO_SCORES` из него же
проверяются тестом `tests/unit/test_control_package.py`. Эта таблица — их отражение.

## Состав

- **50 строк** (одна на контрагента), заголовок — фиксированные колонки листа «Контрагенты».
- **38 пригодных** строк (`EXPECTED_USABLE`): попадают в результат разбора.
- **12 строк с проблемами** (`EXPECTED_ISSUES`): 11 ошибок (строка отбрасывается) и
  1 предупреждение (`duplicate_row` — полный дубль объединяется, второй раз не считается).

Строка ИНН хранится текстом (формат `@`), чтобы ведущие и контрольные цифры не терялись.
Значения не превращаются в формулы; единственная формула — намеренная (см. `formula_forbidden`).

## Демонстрационные оценки

Каждому пригодному контрагенту заранее присвоена **демонстрационная** оценка приоритета
для будущего демоотчёта (S2-05). Это фиксированные показательные значения, а не расчёт:
реальные приоритеты появятся в спринте 3 (`docs/scoring.md`). Распределение покрывает все
пять корзин:

| Приоритет | Строк | Профиль строки |
| --- | --- | --- |
| `unknown` | 8 | только ИНН, внутренних сигналов нет |
| `low` | 8 | долг, просрочка 0, дата среза = дате анализа |
| `medium` | 8 | просрочка 45 дней |
| `high` | 7 | просрочка 90 дней |
| `critical` | 7 | как `high`, но приоритет задан демо (реальный `critical` требует внешнего события) |

## Ожидаемые ошибки

Номер строки — как в Excel (заголовок — строка 1).

| Строка | Код | Серьёзность | Колонка | Что смоделировано |
| --- | --- | --- | --- | --- |
| 40 | `inn_missing` | error | A | ИНН пуст |
| 41 | `inn_invalid` | error | A | неверная контрольная цифра (`0000000001`) |
| 42 | `formula_forbidden` | error | B | формула вместо значения |
| 43 | `debt_not_number` | error | D | сумма долга не число |
| 44 | `debt_negative` | error | D | отрицательный долг |
| 45 | `overdue_not_integer` | error | E | дни просрочки не целое |
| 46 | `cutoff_required` | error | — | есть долг, нет даты среза |
| 47 | `cutoff_mismatch` | error | C | дата среза не совпадает с датой анализа |
| 48 | `last_payment_future` | error | F | дата последнего платежа позже даты анализа |
| 49 | `inn_conflict` | error | A | тот же ИНН, что у строки 2, но другие данные |
| 50 | `duplicate_row` | warning | — | полный дубль строки 3 — объединяется |
| 51 | `name_invalid` | error | B | наименование не текст |

Причины ошибок не содержат сырых ИНН и содержимого ячеек (проверяется тестом).

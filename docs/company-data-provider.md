# Контракт проверки контрагента — S1-04

Реализован для ревью общих типов; интеграция в Telegram относится к задачам A S1-02/S1-03. Реальный Checko — задача B S1-05. Новых зависимостей нет.

## Что подключать разработчику A

```python
import asyncio

from claims_assistant.application.company_data import CompanyDataProvider, CompanyDataRequest
from claims_assistant.infrastructure.demo.company_data import DemoCompanyDataProvider, DemoScenario


async def example():
    provider: CompanyDataProvider = DemoCompanyDataProvider(DemoScenario.INCOMPLETE)
    # Синтетический идентификатор для примера, не запрос данных реальной компании.
    # Пользовательский ИНН предварительно проверяет общий валидатор из S1-01.
    request = CompanyDataRequest(inn="0000000000")
    for snapshot in await provider.fetch(request):
        print(snapshot.mode, snapshot.section, snapshot.status, snapshot.coverage)
        for fact in snapshot.facts:
            print(fact.kind, fact.value, fact.unit)
        for reason in snapshot.missing:
            print(reason)


asyncio.run(example())
```

Запускать пример после установки пакета по README. Токены, `.env`, сеть и Excel для демопровайдера не нужны. Бот пока не вызывает этот код; его команды не изменились.

## Вход и выход

- Интерфейс: `application.company_data.CompanyDataProvider`, асинхронный `fetch(request)`.
- `CompanyDataRequest`: ИНН-строка, непустой кортеж уникальных `Section`, `RequestLimits`.
- Разделы: `company`, `bankruptcy`, `finances`. По умолчанию запрошены все три.
- Один `ExternalSnapshot` на каждый запрошенный раздел, в том же порядке. ИНН не преобразуется в число.
- Проверка контрольной цифры ИНН остаётся единственной общей функцией S1-01. Этот контракт проверяет тип строки, но не заменяет валидатор A.
- Лимиты: положительные `timeout_seconds`, `max_requests`, `max_pages`. Реальный адаптер обязан соблюдать их; демо не расходует запросы и страницы. Общий бюджет всей проверки контролирует прикладной сценарий.
- Ожидаемый сбой источника возвращается в разделе через `status`, `error` и `missing`. Программные ошибки и отмена выполнения не маскируются под пустой результат.

## Снимки, факты и основания

Общие типы находятся в `domain.external`; это Python-объекты для обмена между модулями, не формат JSON Checko или таблицы БД.

`ExternalSnapshot` содержит раздел, ИНН, источник, режим `demo/live`, время получения, статус, полноту, покрытый период, факты, основания и причины пропусков. Время обновления источника необязательно: его нельзя заменять временем загрузки. Технические даты требуют часового пояса и нормализуются в UTC.

Каждый `Fact` имеет ID, тип `kind`, точное значение, дату/период и ссылки на `Evidence` того же снимка. Основание содержит имя источника и ID записи; URL необязателен. Неизвестное значение — `None` с причиной; известный ноль не означает пропуск. Денежные примеры используют `Decimal` и единицу `RUB`; `float`, `NaN` и бесконечность в значении факта отклоняются.

Ссылки проверяются при создании снимка: чужой ИНН, неизвестное основание или повторный ID отклоняются. Частичному результату нужны причины. Неуспешный раздел не содержит успешных фактов и обязательно имеет безопасную ошибку. Частичные успешные данные допустимы как `status=ok, coverage=partial`.

`kind` пока является строкой: набор демопримеров — `company_name`, `company_status`, `revenue`, `net_profit`, `bankruptcy_event`. Справочник реальных событий и нормализация Checko уточняются в отдельном PR адаптера; демопример не фиксирует схему поставщика.

## Демосценарии

Сценарий явно задаётся при создании провайдера и не выбирается по ИНН.

| Сценарий | Организация | Сообщения | Финансы |
| --- | --- | --- | --- |
| `ORDINARY` | Вымышленное название, активный статус | Полная пустая выборка за 2025 год | Выручка и известная нулевая прибыль за 2025 год |
| `ALARM` | Вымышленное название, активный статус | Синтетическое сообщение о наблюдении | Те же демонстрационные финансы |
| `INCOMPLETE` | Раздел доступен | Пустая выборка только за декабрь; остальной год неизвестен | Источник недоступен |
| `ERROR` | Источник недоступен | Источник недоступен | Источник недоступен |

Все результаты помечены `mode=demo`, источник — `synthetic-demo-v1`. Даты фиксированы: события/финансы 2025 года, время получения 01.01.2026 UTC. Это воспроизводимые фикстуры, а не сведения о текущем состоянии реестров. Ссылок на реальные компании и внешних URL нет.

В карточке всегда показывать деморежим, полноту и покрытый период. «Полная» относится только к указанному разделу и диапазону; она не означает надёжность контрагента. Приоритеты и юридические рекомендации этот модуль не вычисляет. Ошибка live-адаптера никогда не переключает проверку на этот провайдер.

### Подключение второго разработчика

1. Получить доступ к [репозиторию](https://github.com/Sopkas/artemProd), если он требуется; клонировать его в свою рабочую папку.
2. Прочитать [журнал](../PROJECT_STATUS.md), [README](../README.md) и этот чеклист.
3. Выполнить установку и проверки по README. Поддерживаемый для этой инструкции путь — macOS/Linux; на Windows можно использовать WSL. Нативный Windows отдельно не проверен.
4. Создать собственного тестового бота через `@BotFather`, заполнить локальный `.env` и добавить свой Telegram ID. Токен не отправлять в PR или журнал.
5. Запустить бота и пройти чеклист. Использовать отдельный токен: два polling-процесса с одним ботом мешают друг другу.
6. Просмотреть уточнение интерфейсов и выбрать одну задачу спринта 1: коллега берёт направление A, Sopkas — B. Создать отдельную ветку; следующий PR проверяет другой разработчик.

### Ручная проверка Telegram

- [ ] `/start` показывает приветствие и две кнопки меню.
- [ ] `/help` и «Помощь» показывают одинаковую справку.
- [ ] `/about` и «О сервисе» показывают одинаковое описание.
- [ ] Произвольный текст и неизвестная команда получают подсказку.
- [ ] Файл, включая файл с подписью `/start`, получает сообщение о недоступности загрузки.
- [ ] Пользователь вне списка получает только отказ со своим Telegram ID.
- [ ] Бот не отвечает в группе.
- [ ] После `Ctrl+C` процесс останавливается; повторный запуск работает.

Для результата записать дату, проверенную версию и пройденные пункты. Токены, содержимое чужой переписки и финансовые данные в журнал не добавлять.

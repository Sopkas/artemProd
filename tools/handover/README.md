# Материалы для заказчика

Сборка комплекта, который отдаётся заказчику вместе с обновлением бота:
- инструкция пользователя (PDF);
- памятка к пробной проверке (PDF);
- таблица сравнения;
- шаблоны файлов.

| Файл | Что делает |
| --- | --- |
| `make_guide.py` | Инструкция для заказчика: `docs/user-guide.md` плюс таблица ограничений **последнего** выпуска из `docs/release-notes.md`. Ссылки на документы репозитория и номера задач убираются |
| `memo.md` | Текст памятки к пробной проверке. Правится руками под выпуск |
| `md2pdf.py` | Markdown → PDF (reportlab, Arial). Значки карточки (❗️ ⚠️ ✅ 🔺 …) рисуются из системного шрифта эмодзи картинками, «₽» — шрифтом, где он есть. Нужен macOS: шрифты берутся из `/System/Library/Fonts` |
| `make_xlsx.py` | Таблица сравнения и шаблоны — теми же функциями, что в боте |

```bash
# отдельное окружение: эти библиотеки боту не нужны
python3 -m venv /tmp/pdfenv && /tmp/pdfenv/bin/pip install reportlab pypdf pillow
OUT=out && mkdir -p $OUT
PYTHONPATH=src .venv/bin/python tools/handover/make_xlsx.py $OUT
/tmp/pdfenv/bin/python tools/handover/make_guide.py . /tmp/guide.md
/tmp/pdfenv/bin/python tools/handover/md2pdf.py /tmp/guide.md "$OUT/1. Инструкция пользователя.pdf" \
  "Инструкция пользователя" "Бот для претензионной работы — инструкция пользователя, версия 0.2.0"
/tmp/pdfenv/bin/python tools/handover/md2pdf.py tools/handover/memo.md "$OUT/2. Памятка к пробной проверке.pdf" \
  "Памятка к пробной проверке" "Бот для претензионной работы — памятка к пробной проверке, версия 0.2.0"
```

**Перед выпуском:**
- сменить версию в `make_guide.py`, `memo.md` и в подписях команд выше;
- открыть PDF и посмотреть страницы глазами — значки и «₽» должны быть видны, а не квадратами.

# Инструкции ИИ

Здесь будут версионируемые инструкции для объяснения результатов и анализа комментариев. Текст инструкции добавляется вместе со схемой ответа и контрольными примерами.

Инструкция должна отделять факты от слов клиента, требовать ссылки на переданные основания, сохранять рассчитанный приоритет и обозначать недостающие данные. Реальные комментарии и сведения клиентов в эту папку не добавляются.

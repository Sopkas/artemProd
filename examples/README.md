# Шаблоны и демонстрационные данные

Здесь будут `.xlsx` по [контрактам данных](../docs/data-contracts.md): контрагенты, платежи, взаимодействия и история долга, а также пример итогового отчёта.

На текущем этапе Excel-файлы ещё не созданы. Будущие примеры должны быть синтетическими и явно помеченными как демонстрационные. Они не должны отправляться в реальные API или содержать реальные данные должников.

# Шаблоны и демонстрационные данные

## Демонстрационный пакет (S6-04)

Четыре контрагента для показа продукта: обычный должник, серьёзный сигнал, ухудшение платежей и неполные данные. Ни одна оценка не подставлена — все четыре приоритета считают правила из `docs/scoring.md`.

```bash
PYTHONPATH=src python demo_package.py --what   # состав и что про кого говорить
PYTHONPATH=src python demo_package.py          # собрать .xlsx в examples/demo/
```

Файлы в репозиторий не кладутся: скрипт собирает одни и те же байты при каждом запуске, поэтому репетиция и защита показывают одинаковые числа. Ход показа — `docs/demo-script.md`; определения пакета — `src/claims_assistant/infrastructure/demo/package.py`.

Чтобы бот отвечал по этому пакету, в `.env`: `DATA_PROVIDER=demo`, `DEMO_PACKAGE=true`, `AI_PROVIDER=stub`. Без `DEMO_PACKAGE` источник даёт один сценарий на всех, и четыре истории превращаются в одну.

## Шаблоны файлов

Пустые шаблоны по [контрактам данных](../docs/data-contracts.md) бот присылает сам из диалога проверки: «Контрагенты», «Платежи», «История долга», «Взаимодействия».

Всё здесь синтетическое и помечено как демонстрационное. Настоящие данные должников в репозиторий не попадают и в реальные API из этих примеров ничего не уходит.
